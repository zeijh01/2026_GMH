Step2. 나이스 Open API로 급식 데이터 가져오기

Step1에서 API 요청-응답 구조와 JSON을 다뤘다는 전제로 진행한다.

01나이스 Open API 소개

나이스(NEIS)는 전국 학교의 급식, 학사일정, 학교 기본정보 등을 공개 API로 제공한다. 제공처: open.neis.go.kr

준비물 — 인증키 발급
open.neis.go.kr 접속 → 오픈API 활용신청 → 급식식단정보 서비스 신청 → 발급된 인증키(KEY)를 복사해둔다.

02필요한 API 두 개

급식 데이터를 가져오려면 학교 코드가 필요하다. 학교 이름만으로는 요청할 수 없기 때문에, 먼저 학교 이름으로 코드를 찾는 API를 호출하고, 그 코드로 급식 API를 호출하는 2단계 과정을 거친다.

학교 검색https://open.neis.go.kr/hub/schoolInfo — 교육청 코드 + 학교 이름 → 학교 코드
급식 조회https://open.neis.go.kr/hub/mealServiceDietInfo — 교육청 코드 + 학교 코드 + 날짜 → 급식 메뉴

03학교 코드 찾기

학교 이름만으로 검색하면 다른 지역에 같은 이름의 학교가 있을 때 엉뚱한 학교가 나올 수 있다. 우리 학교가 속한 교육청 코드를 미리 알고 있으니, 검색할 때 같이 넘겨서 그 교육청 안으로 범위를 좁힌다.

meal_practice.py
import requests

API_KEY = "발급받은_인증키"

def find_school(office_code, school_name):
    url = "https://open.neis.go.kr/hub/schoolInfo"
    params = {
        "KEY": API_KEY,
        "Type": "json",
        "pIndex": 1,
        "pSize": 5,
        "ATPT_OFCDC_SC_CODE": office_code,
        "SCHUL_NM": school_name
    }
    response = requests.get(url, params=params)
    data = response.json()
    school = data["schoolInfo"][1]["row"][0]
    return school["SD_SCHUL_CODE"]

office_code = "J10"   # 경기도교육청 — 우리 학교가 속한 교육청 코드
school_code = find_school(office_code, "광명고등학교")
print(school_code)
실행 결과 확인하기 
7530580

응답 데이터의 구조가 ["schoolInfo"][1]["row"][0]처럼 조금 복잡하다. 나이스 API는 응답을 head(요청 정보)와 row(실제 데이터 목록) 두 부분으로 나눠서 주기 때문이다. [0]이 head, [1]이 row다.

schoolInfo 실제 응답 (일부 필드만 표시)
{
  "schoolInfo": [
    {
      "head": [
        { "list_total_count": 1 },
        { "RESULT": { "CODE": "INFO-000", "MESSAGE": "정상 처리되었습니다." } }
      ]
    },
    {
      "row": [
        {
          "ATPT_OFCDC_SC_CODE": "J10",
          "ATPT_OFCDC_SC_NM": "경기도교육청",
          "SD_SCHUL_CODE": "7530580",
          "SCHUL_NM": "광명고등학교",
          "ENG_SCHUL_NM": "Gwangmyeong High School"
        }
      ]
    }
  ]
}

이 구조를 인덱스로 하나씩 따라가면 이렇다.

data["schoolInfo"]리스트. 안에 head 객체 1개, row 객체 1개가 순서대로 들어있다.
["schoolInfo"][0]head. 요청이 성공했는지, 검색 결과가 총 몇 건인지 같은 부가 정보.
["schoolInfo"][1]row. 실제 찾고자 한 학교 데이터가 리스트로 들어있다.
["schoolInfo"][1]["row"]학교 목록. 교육청으로 범위를 좁혀도 검색 결과가 여러 개면 이 리스트에 여러 개가 들어있다.
["schoolInfo"][1]["row"][0]검색된 첫 번째 학교의 정보 딕셔너리. ["SD_SCHUL_CODE"]처럼 키로 원하는 값을 꺼낸다.

04급식 데이터 가져오기

meal_practice.py — 이어서 작성
def get_meal(office_code, school_code, date):
    url = "https://open.neis.go.kr/hub/mealServiceDietInfo"
    params = {
        "KEY": API_KEY,
        "Type": "json",
        "pIndex": 1,
        "pSize": 5,
        "ATPT_OFCDC_SC_CODE": office_code,
        "SD_SCHUL_CODE": school_code,
        "MLSV_YMD": date   # YYYYMMDD 형식
    }
    response = requests.get(url, params=params)
    data = response.json()

menu = get_meal(office_code, school_code, "20250915")
print(menu)

05전체 코드로 합치기

지금은 find_school()을 매번 호출해서 학교 코드를 찾는다. 매번 검색하는 건 비효율적이지만, 지금 단계에서는 정확하게 동작하는 것이 우선이다. 캐싱으로 개선하는 것은 Streamlit에 익숙해진 뒤 심화 내용으로 다룬다.

정리

  • 학교 이름만으로는 급식 데이터를 바로 조회할 수 없고, 학교 코드를 먼저 찾아야 한다.
  • 나이스 API 응답은 [head, row] 구조이고, 실제 데이터는 row에 있다.
  • 날짜 파라미터는 YYYYMMDD 형식의 문자열로 넘긴다.
한 걸음 더 — 메뉴 데이터 정리하기

get_meal()이 돌려주는 값은 아직 가공 전이다.

1. <br/>로 이어붙은 메뉴를 리스트로 쪼갠다.

raw = "백미밥<br/>콩나물국<br/>제육볶음5.6.13"
dishes = raw.split("<br/>")
print(dishes)
# ['백미밥', '콩나물국', '제육볶음5.6.13']

여기까지는 문제없다. 그런데 실제 학교로 조회해보면 메뉴 이름에 알레르기 번호 말고도 여러 표시가 섞여 나온다.

['압맥보리밥(고)', '연포탕! (13.18)', '양배추찜/깻잎찜쌈장! (1.5.6.13)',
 '돈육고추장불고기* (5.6.10.13.16)', '섞박지(고) (9)', '파인애플생과!', '[선택]메론']

알레르기 번호는 괄호 안에 있고, (고)처럼 숫자가 아닌 표시도 있고, 섞박지(고) (9)처럼 괄호가 두 번 나오기도 한다. 끝에 *나 !가 붙기도 하고, [선택]처럼 대괄호 태그가 맨 앞에 붙기도 한다. 뒤에서부터 숫자만 잘라내는 방식으로는 이걸 처리할 수 없다 — 괄호 안이 숫자가 아닐 때도 있고, 애초에 문자열이 )로 끝나서 첫 글자부터 걸린다.

2. 정규표현식(re)으로 괄호·대괄호 구간을 한 번에 지운다.

import re

def clean_dish_name(dish):
    dish = re.sub(r"[\(\[].*?[\)\]]", "", dish)   # 괄호/대괄호와 그 안 내용을 빈 문자열로 치환
    return dish.strip("*! ")                       # 남은 *, !, 공백을 양 끝에서 제거

re.sub(패턴, 바꿀 문자열, 대상)은 패턴에 걸리는 부분을 찾아서 바꾼다. 여기서는 빈 문자열로 바꾸니 결과적으로 삭제하는 셈이다. 패턴을 하나씩 뜯어보면 이렇다.

[\(\[]여는 괄호 하나 — ( 또는 [.
.*?그 사이의 아무 문자나, 가능한 한 짧게 매칭한다. ?가 없으면 섞박지(고) (9)처럼 괄호가 두 번 나올 때 첫 (부터 마지막 )까지를 통째로 한 덩어리로 묶어버릴 수 있다.
[\)\]]닫는 괄호 하나 — ) 또는 ].

실제 데이터로 확인하면 이렇게 정리된다.

samples = ['압맥보리밥(고)', '연포탕! (13.18)', '양배추찜/깻잎찜쌈장! (1.5.6.13)',
           '돈육고추장불고기* (5.6.10.13.16)', '섞박지(고) (9)', '파인애플생과!', '[선택]메론']

print([clean_dish_name(d) for d in samples])
# ['압맥보리밥', '연포탕', '양배추찜/깻잎찜쌈장', '돈육고추장불고기', '섞박지', '파인애플생과', '메론']

두 단계를 합치면 이렇다.

import re

def clean_dish_name(dish):
    dish = re.sub(r"[\(\[].*?[\)\]]", "", dish)
    return dish.strip("*! ")

def clean_menu(raw):
    dishes = raw.split("<br/>")
    return [clean_dish_name(d) for d in dishes]

menu = get_meal(office_code, school_code, "20250915")
print(clean_menu(menu))
