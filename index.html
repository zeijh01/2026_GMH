해커톤 수업자료

급식알리미 만들기

나이스(NEIS) 교육정보 개방포털 API로 우리 학교 급식을 보여주는 웹앱을, Streamlit과 AI 코딩 도구를 이용해 처음부터 배포까지 직접 만들어본다.

각 단계는 이전 단계에서 이어진다. 순서대로 Step0부터 진행하고, 이미 끝낸 단계가 있다면 해당 카드를 눌러 바로 이동해도 된다. 모든 페이지 상단의 🏠 메인 버튼을 누르면 언제든 이 페이지로 돌아온다.
진행 순서
Step 0

개발 환경 준비

Python, VS Code, 가상환경(venv)을 설치하고 실습 준비를 마친다.

시작하기 → Step 1

API 기초

API가 무엇인지, JSON과 상태 코드는 무엇을 뜻하는지 익힌다.

시작하기 → Step 2

나이스 API로 급식 데이터 가져오기

학교 코드를 조회하고, 급식 정보 API를 호출해 오늘의 메뉴를 받아온다.

시작하기 → Step 3

Streamlit 기초

제목, 선택창, 버튼 같은 위젯을 조합해 급식알리미 웹앱 화면을 만든다.

시작하기 → Step 4

Streamlit 배포하기

GitHub와 Streamlit Community Cloud로 앱을 인터넷에 공개한다. API 키를 안전하게 숨기는 방법도 함께 다룬다.

시작하기 → Step 5

바이브코딩으로 내 앱 확장하기

AI 코딩 도구와 함께 즐겨찾기, 디자인 개선, 캐싱까지 직접 기능을 추가해본다.

Bonus

하네스 엔지니어링 — AI 에이전트 팀 설계하기

여러 AI 에이전트가 역할을 나눠 협업하는 구조를 이해하고, 작은 2인 팀 하네스를 직접 설계해본다. Step0~5를 마친 뒤 시간이 남는 팀을 위한 심화 활동이다.

오늘 하루의 흐름
  1. Step0에서 개발 환경을 준비하고, Step1~2에서 API로 급식 데이터를 받아오는 법을 익힌다.
  2. Step3에서 Streamlit으로 화면을 만들고, Step4에서 실제로 인터넷에 배포한다.
  3. Step5에서 AI와 함께 즐겨찾기·디자인·캐싱 같은 기능을 자유롭게 확장한다.
  4. 시간이 남으면 추가 탐구 활동으로 하네스 엔지니어링을 실습해본다.
