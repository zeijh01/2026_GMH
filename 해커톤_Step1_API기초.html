Step1. API란 무엇인가

Step0에서 개발 환경 설정을 마쳤다는 전제로 진행한다.

01왜 필요한가

급식 메뉴를 확인하려면 학교 홈페이지에 들어가서 공지사항을 찾아야 한다. 매일 이렇게 확인하는 건 번거롭다. 학교 서버에 있는 급식 데이터를 코드로 바로 가져올 수 있다면, 이 과정을 자동화할 수 있다. 이걸 가능하게 해주는 것이 API다.

02API의 요청-응답 구조

API는 "내가 원하는 데이터를 정해진 형식으로 요청하면, 정해진 형식으로 응답을 돌려주는 창구"다.

내 코드
요청 (Request)
→URL + 파라미터
서버
데이터 처리
→JSON 응답
내 코드
응답 (Response)

요청을 보낼 때 필요한 것은 크게 세 가지다: URL(어디에 요청하는지), 파라미터(무엇을 요청하는지), 응답 형식(결과를 어떤 형태로 받을지 — 보통 JSON).

03JSON — API가 주고받는 데이터 형식

데이터는 구조를 가진 정도에 따라 세 가지로 나뉜다.

정형 데이터행과 열이 고정된 표 형태. 엑셀, 데이터베이스 테이블.
반정형 데이터구조는 있지만 행과 열처럼 고정되어 있지 않다. 항목마다 필드 개수나 중첩 구조가 달라질 수 있다. JSON, XML이 여기에 속한다.
비정형 데이터구조가 없다. 사진, 영상, 자유 형식의 텍스트.

API는 대부분 JSON으로 응답한다. JSON은 키: 값 쌍으로 이루어지고, 값 자리에 또 다른 객체({})나 리스트([])가 중첩될 수 있다. 표와 달리 항목마다 필드 구성이 달라져도 표현할 수 있는 이유가 이 중첩 구조 때문이다.

{
  "userId": 1,
  "id": 1,
  "title": "sunt aut facere...",
  "tags": ["study", "python"]
}

파이썬에서는 {}가 딕셔너리, []가 리스트로 그대로 대응된다. .json()으로 변환하면 파이썬의 딕셔너리·리스트 문법으로 값을 꺼낼 수 있다. 뒤에서 나이스 API 응답을 다룰 때 ["schoolInfo"][1]["row"][0]처럼 대괄호를 여러 번 쓰는 이유도 이 중첩 구조 때문이다.

05첫 API 호출

인증키가 필요 없는 공개 API로 먼저 연습한다.

api_practice.py
import requests

url = "https://jsonplaceholder.typicode.com/posts/1"
response = requests.get(url)

print(response.status_code)   # 200이면 성공
print(response.json())        # 딕셔너리 형태로 변환된 응답

response.status_code는 요청이 어떻게 처리됐는지 알려주는 숫자다. 자주 마주치는 코드는 다음과 같다.

200 OK요청 성공. 정상적으로 데이터를 받았다.
400 Bad Request요청 파라미터가 잘못됐다.
401 Unauthorized인증키가 없거나 잘못됐다.
403 Forbidden접근 권한이 없다.
404 Not Found요청한 주소(URL)를 찾을 수 없다.
500 Internal Server Error서버 쪽에서 오류가 발생했다.

200번대는 성공, 400번대는 요청(내 쪽) 문제, 500번대는 서버 쪽 문제로 구분해서 기억해두면 오류를 마주쳤을 때 원인을 좁히기 쉽다.

실행 결과 확인하기 
200
{'userId': 1, 'id': 1, 'title': 'sunt aut facere...', 'body': 'quia et suscipit...'}

response.json()은 서버가 돌려준 JSON 텍스트를 파이썬 딕셔너리로 바꿔준다. 이후 ["title"]처럼 딕셔너리 키로 원하는 값만 꺼낼 수 있다.

api_practice.py — 원하는 값만 꺼내기
data = response.json()
print(data["title"])

06파라미터가 있는 요청

대부분의 실제 API는 URL만으로 끝나지 않고, 어떤 데이터를 원하는지 파라미터로 지정해야 한다. params 인자에 딕셔너리로 넘기면 requests가 알아서 URL 뒤에 붙여준다.

params = {
    "userId": 1
}
response = requests.get("https://jsonplaceholder.typicode.com/posts", params=params)
print(len(response.json()), "개의 게시물")

정리

  • API는 URL + 파라미터로 요청하고, JSON으로 응답받는 구조다.
  • requests.get(url, params=...)로 요청을 보낸다.
  • .json()으로 응답을 파이썬 딕셔너리로 바꿔서 다룬다.
