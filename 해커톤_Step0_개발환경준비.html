Step0. 개발 환경 준비

급식알리미 만들기 실습을 위한 사전 준비 단계. Python과 VS Code를 처음 쓰는 경우에 진행한다.

01파이썬 설치

  1. python.org/downloads에 접속해 최신 버전을 다운로드한다.
  2. 설치 화면 맨 아래 "Add python.exe to PATH" 체크박스를 반드시 체크한다.
  3. Install Now를 눌러 설치를 진행한다.
  4. 설치가 끝나면 터미널을 열고 python --version을 입력해 버전이 출력되는지 확인한다.
환경변수(PATH)란
운영체제가 특정 명령어를 입력받았을 때 어떤 프로그램을 실행할지 찾아보는 폴더 목록이다. python이라고 입력했을 때 실행되려면, 파이썬이 설치된 폴더가 이 목록(PATH)에 등록되어 있어야 한다. 설치 시 체크박스를 눌렀다면 자동으로 등록된다. 체크를 놓쳐서 python --version이 인식되지 않는다면, 파이썬을 삭제 후 체크박스를 확인하며 재설치하는 것이 가장 확실하다.

02VS Code 설치 및 확장 프로그램

  1. code.visualstudio.com에서 VS Code를 다운로드하고 설치한다.
  2. 왼쪽 사이드바에서 Extensions(네모 4개 아이콘)를 클릭한다.
  3. "Python"을 검색해 Microsoft에서 배포한 Python 확장을 설치한다.
  4. .py 파일을 열었을 때 화면 하단 상태바에 파이썬 버전이 표시되면 정상이다.

03가상환경(venv) 만들기

프로젝트마다 필요한 라이브러리 버전이 다를 수 있다. 컴퓨터 전체에 라이브러리를 설치하면 프로젝트끼리 버전이 충돌할 수 있어서, 프로젝트별로 독립된 설치 공간을 만들어 쓴다. 이것이 가상환경이다.

  1. VS Code에서 파일 → 폴더 열기로 프로젝트 폴더를 연다.
  2. 터미널 → 새 터미널(또는 Ctrl + `)로 터미널을 연다.
  3. 가상환경을 만든다: python -m venv venv
  4. 가상환경을 활성화한다.
    Windows
    venv\Scripts\activate
    Mac / Linux
    source venv/bin/activate
  5. 터미널 맨 앞에 (venv)가 표시되면 활성화된 것이다. 이 상태에서 설치하는 라이브러리는 이 프로젝트 안에서만 적용된다.
  6. VS Code 오른쪽 아래에 표시된 파이썬 버전을 클릭해, 방금 만든 venv의 인터프리터를 선택한다.
참고
터미널을 새로 열 때마다 (venv) 표시가 사라져 있으면 4번 명령으로 다시 활성화해야 한다. VS Code가 인터프리터로 venv를 기억하고 있으면 폴더를 열 때 자동으로 활성화해주는 경우도 있다.

04라이브러리 설치 확인

  1. 가상환경이 활성화된 상태에서 pip install requests를 실행한다.
  2. pip list를 입력했을 때 목록에 requests가 보이면 완료다.
