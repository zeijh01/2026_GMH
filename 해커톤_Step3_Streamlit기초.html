Step3. Streamlit으로 화면 만들기

Step0~2에서 만든 함수를 그대로 가져와 웹 화면에 연결한다. 각 코드 옆에 실제로 어떤 화면이 뜨는지 나란히 붙여뒀다.

01Streamlit이란

지금까지 만든 함수는 터미널에서만 실행됐다. Streamlit은 같은 파이썬 코드를 웹 화면으로 바꿔주는 라이브러리다. HTML, CSS, JavaScript를 몰라도 파이썬 코드만으로 화면을 만들 수 있다.

핵심 동작 원리
Streamlit은 화면의 위젯(입력창, 버튼 등) 값이 바뀔 때마다 .py 파일 전체를 위에서부터 다시 실행한다.
학교 이름을 입력하고 Enter를 치는 순간 전체 코드가 처음부터 다시 돌아간다는 뜻이다.
이 특성 때문에 04번에서 버튼으로 실행 시점을 제어하는 방법이 필요해지고, 나중에 캐싱도 필요해진다.

02실습 준비

  1. VS Code에서 프로젝트 폴더를 열고 가상환경을 활성화한다 (처음이면 Step0 참고).
  2. 터미널에서 pip install streamlit을 실행한다.
  3. 새 파일 app.py를 만든다.
  4. 터미널에서 streamlit run app.py를 실행한다. 브라우저가 자동으로 열린다.
참고
코드를 저장(Ctrl+S)하면 브라우저 화면이 자동으로 새로고침되지 않을 수 있다.
그럴 땐 브라우저 우측 상단에 뜨는 Rerun 버튼을 누르면 된다.

03화면에 글자 출력하기

st.title()은 제목을, st.write()는 일반 텍스트를 화면에 출력한다.

app.py
import streamlit as st

st.title("급식알리미")
st.write("오늘 우리 학교 급식을 확인하세요.")
브라우저 화면
급식알리미
오늘 우리 학교 급식을 확인하세요.

04사용자 입력받기

st.text_input()은 텍스트 입력창을, st.date_input()은 날짜 선택창을 만든다. 둘 다 사용자가 입력한 값을 반환한다.

app.py
school_name = st.text_input("학교 이름을 입력하세요")
date = st.date_input("날짜를 선택하세요")

st.write(f"입력한 학교: {school_name}")
브라우저 화면
학교 이름을 입력하세요
날짜를 선택하세요
입력한 학교: 광명고등학교

입력창 값이 바뀔 때마다 01에서 본 것처럼 스크립트 전체가 다시 실행되고, st.write()가 즉시 갱신된다.

05버튼으로 실행 시점 제어하기

학교 이름이나 날짜는 바뀔 때마다 바로 반영돼도 괜찮지만, API 요청처럼 시간이 걸리는 작업은 사용자가 원할 때만 실행되면 좋겠다. if st.button(...): 블록 안에 넣으면 버튼을 눌렀을 때만 그 안의 코드가 실행된다.

app.py
if st.button("급식 조회하기"):
    st.write("조회 버튼을 눌렀습니다.")

06지금까지 배운 함수와 연결하기

Step2에서 만든 find_school(), get_meal(), clean_dish_name(), clean_menu()를 그대로 가져와 화면에 연결한다. 교육청 코드는 아직 화면 위젯 없이 코드에 직접 적어둔다 — 07에서 selectbox로 바꾼다.

app.py — 전체
import streamlit as st
import requests
import re

API_KEY = "발급받은_인증키"
office_code = "J10"   # 경기도교육청 — 우리 학교가 속한 교육청 코드

def find_school(office_code, school_name):
    url = "https://open.neis.go.kr/hub/schoolInfo"
    params = {
        "KEY": API_KEY, "Type": "json",
        "pIndex": 1, "pSize": 5,
        "ATPT_OFCDC_SC_CODE": office_code,
        "SCHUL_NM": school_name
    }
    data = requests.get(url, params=params).json()
    school = data["schoolInfo"][1]["row"][0]
    return school["SD_SCHUL_CODE"]

def get_meal(office_code, school_code, date):
    url = "https://open.neis.go.kr/hub/mealServiceDietInfo"
    params = {
        "KEY": API_KEY, "Type": "json",
        "pIndex": 1, "pSize": 5,
        "ATPT_OFCDC_SC_CODE": office_code,
        "SD_SCHUL_CODE": school_code,
        "MLSV_YMD": date
    }
    data = requests.get(url, params=params).json()
    return data["mealServiceDietInfo"][1]["row"][0]["DDISH_NM"]

def clean_dish_name(dish):
    dish = re.sub(r"[\(\[].*?[\)\]]", "", dish)
    return dish.strip("*! ")

def clean_menu(raw):
    return [clean_dish_name(d) for d in raw.split("<br/>")]

st.title("급식알리미")

school_name = st.text_input("학교 이름을 입력하세요")
date = st.date_input("날짜를 선택하세요")

if st.button("급식 조회하기"):
    school_code = find_school(office_code, school_name)
    date_str = date.strftime("%Y%m%d")
    raw_menu = get_meal(office_code, school_code, date_str)
    menu = clean_menu(raw_menu)

    st.write(f"### {school_name} {date_str} 급식")
    for dish in menu:
        st.write(f"- {dish}")

07교육청 선택하기

지금은 교육청 코드를 "J10"으로 코드에 직접 적어뒀다. 이러면 경기도 학교만 조회할 수 있다. st.selectbox()로 교육청을 고르게 하면 전국 어느 학교든 조회할 수 있다.

offices는 교육청 이름과 코드를 짝지어둔 딕셔너리다. 사용자는 이름으로 고르고, 코드는 딕셔너리에서 바로 꺼내 쓴다. 이제 find_school(office_code, school_name)에 하드코딩된 값 대신 이 office_code를 넘기면 된다.

08위젯 나란히 배치하기

교육청을 고른 다음엔 학교 이름과 날짜를 입력받는다. 지금은 입력창들이 위아래로 길게 늘어서 있다. st.columns()로 화면을 여러 칸으로 나눠서 옆으로 배치할 수 있다.

app.py
col1, col2 = st.columns(2)
with col1:
    school_name = st.text_input("학교 이름을 입력하세요")
with col2:
    date = st.date_input("날짜를 선택하세요")
브라우저 화면
학교 이름을 입력하세요
날짜를 선택하세요

with col1: 블록 안에 넣은 위젯은 첫 번째 칸에, with col2: 안에 넣은 위젯은 두 번째 칸에 배치된다.

09로딩 표시하기

API 요청은 시간이 조금 걸린다. 그동안 화면이 멈춘 것처럼 보이지 않도록 로딩 표시를 띄운다.

app.py
with st.spinner("급식 정보를 불러오는 중..."):
    raw_menu = get_meal(office_code, school_code, date_str)
브라우저 화면 — 요청하는 동안
급식 정보를 불러오는 중...

with 블록 안의 코드가 끝날 때까지만 표시되고, 끝나면 자동으로 사라진다.

정리

  • Streamlit은 위젯 값이 바뀔 때마다 스크립트 전체를 처음부터 다시 실행한다.
  • if st.button(...):로 이 재실행 안에서 특정 코드만 조건부로 실행되게 만든다.
  • Step1~2에서 만든 함수를 수정 없이 그대로 가져와 화면에 연결했다.
  • selectbox·columns·spinner·success/error·expander·balloons로 화면을 다듬었다.
다음 — 학교 이름을 바꿀 때마다 find_school()이 매번 다시 호출되는 비효율은 아직 남아있다. 이 부분은 st.cache_data를 다루는 심화 단계에서 정리한다.
